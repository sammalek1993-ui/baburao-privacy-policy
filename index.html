Privacy Policy — Baburao ka style — Owner

Effective date: October 15, 2026

1. What the extension does

Baburao ka style — Owner is a browser extension for saving, organizing, editing, searching, importing, exporting, and reapplying insurance benefit plan form templates. It operates when the user invokes an action in the extension.

2. Information accessed and collected

When a user chooses to save a plan, the extension reads supported form field labels and values from the active website and saves selected field data as a reusable plan template. It also saves plan titles, categories, favorites, dates, and the page URL associated with a saved plan. Because the source website may contain insurance or health-related information, saved form data could include sensitive information if a field is captured unexpectedly. Users should review captured templates and must not intentionally save patient-identifying or sensitive patient information.

The extension also accepts a locally created owner username, password, and owner PIN. It stores the username and salted cryptographic hashes of the password and PIN, not the plaintext password or PIN. It stores local session expiration information.

3. How information is used

Saved information is used only to display and manage reusable plan templates, populate supported fields on the user's chosen website, search page text, manage local owner access, and perform user-requested actions such as copying plan URLs, opening URLs in tabs, and exporting or importing backup files.

4. Where information is stored and retained

Plan templates, saved URLs, preferences, and owner authentication records are stored locally in the current Chrome profile using chrome.storage.local. The extension does not include an application-operated cloud synchronization or upload service. Data remains stored until the user deletes saved plans, clears extension storage, or removes the extension and its stored data. Exported JSON backups are stored wherever the user chooses to save them and remain under the user's control.

5. Sharing, selling, and transfers

The extension does not sell user data or automatically transmit saved plan templates or owner authentication records to the developer, advertisers, analytics services, or third-party servers. When the user chooses to apply a template, the extension enters data into the currently open website; that website may process submitted data under its own privacy policy. When the user explicitly copies URLs, opens URLs, or exports/imports a backup, information is handled by the browser or destination selected by the user. The extension does not use data for advertising, creditworthiness decisions, or lending.

6. Permissions

activeTab and scripting let the extension interact with the current website when requested. storage stores local plans and owner access settings. tabs opens saved URLs at the user's request. clipboardWrite copies saved URLs when requested. downloads saves user-requested JSON backup files.

7. Security and user choices

Owner passwords and PINs are processed into salted hashes before local storage. Users can edit or delete individual saved plans, export backups, and clear stored extension data. Browser profile access and downloaded backup files should be protected because they may contain saved form data. No security method can guarantee absolute protection.

8. Children

This extension is intended for adult professional users and is not directed to children.

9. Changes

This policy may be updated when extension features or data practices change. The latest version will be posted at this URL with an updated effective date.
