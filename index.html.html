The extension reads supported website form fields when a user chooses to save or apply reusable insurance benefit plan templates. Saved plans and owner authentication settings are stored in the current Chrome profile using local extension storage. They are not synchronized through a built-in cloud service.

Users may export templates as JSON, copy stored URLs, or open them. Exports or URLs may contain sensitive information if inadvertently captured from a website. Do not save patient-identifying information. Filtering has not been verified on every website.

The reviewed v3.6.0 extension does not include a built-in remote plan-upload endpoint. Users can delete saved plans or clear extension storage. The extension is not designed to sell user data.
